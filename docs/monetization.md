## 0. 문서의 지위와 의존 전제

### 0.1 지위와 소유권

본 문서는 게임 "회사 경영 시뮬레이션"의 **수익화 단일 정본**이다. README §2.3에 따라 **상품·가격·상점·오퍼**에 관한 결정을 본 문서가 단독 소유하며, 다른 문서는 이를 참조만 한다. 규약 2.1에 따라 **다이아(프리미엄 결제 재화)의 정의권도 본 문서가 단독으로 가진다** — 다이아는 자원 6종(§game-design 2.5)에 속하지 않는 실화폐 결제 재화다.

본 문서는 **게임 규칙을 만들지 않는다.** 규칙·엔티티·자원의 정본은 `game-design.md`이며, 수익화는 그 규칙 위에 얹는 **사업 레이어**다. 규칙 변경이 필요한 제안은 본 문서에서 임의 확정하지 않고 **[game-design 개정 필요]** 태그로 안건화한다(§11에 집약).

### 0.2 의존 전제 (README §1)

- **P1 모바일 우선 · 세로 · 짧은 세션(1~5분) + 자율 주행 방치 플레이** → 시간 단축·오프라인 편의 상품의 근거이자, 상점 UX가 방치 흐름을 끊지 않아야 하는 이유.
- **P2 F2P + IAP · 비(非) 페이 투 윈** → 본 문서의 최상위 제약. 결제는 **시간 단축·편의·확장 편의·코스메틱·구독**에 한정하며, 결제로만 얻는 전투력/승리 독점/타인 대비 우위를 만들지 않는다.
- **P3 미드코어 · 밝고 경쾌** → 포지셔닝(§1.3)과 코스메틱 톤(§3.7)의 좌표.
- **P4 한국어·영어 1차, 일본어·중국어 간체 확장** → 지역별 가격(§4.4).

### 0.3 정합성 계약 (절대 위반 금지 목록)

본 문서의 모든 상품은 아래 불변식을 위반하지 않는다. 위반하는 상품은 무효다.

**게임 경제 불변식 (`game-design.md`):**
1. **회사 간 자금 이전 금지**(§5.9) — 다이아로 산 가치를 특정 회사 자금(₩)에 주입하는 상품 **금지**.
2. **골드→자금 주입 금지**(§5.9, §10.2) — 골드의 소비처는 설립비 하나뿐.
3. **골드 유입 경로 = 청산 반환 유일**(§2.5, §10.2) — 다이아로 골드를 파는 상품 **금지**(새 골드 유입 경로 신설이므로).
4. **슬롯 해금 = 등급 문턱, 구매 불가**(§10.3: "골드 구매 해금도 없음") — 슬롯 판매 **금지**.
5. **자원 6종 외 게임플레이 자원 신설 금지**(§2.4-1) — 다이아·시즌 포인트 등은 게임플레이 자원이 아니며, 일 처리·월말 정산·프로젝트·직원·회사에 개입하지 않는다.
6. **처리 순서에 새 단계 삽입 금지**(§2.4-2) — 다이아 소비는 기존 일 처리 5단계의 하위 작업으로만 표현.
7. **게임오버 없음**(§5.6, §11.6) → **무과금도 완주 가능**을 상품 구조가 훼손하지 않는다.

**내러티브 가드레일 (`narrative-tone.md` §8):**
- 결제 압박 금지(§8-5), FOMO·긴급 과장 금지(§8-2), 거짓 희소성·조작적 카운트다운 금지(§8-6), 죄책감 프레이밍 금지(§8-1), 직원 존엄(§8-4), 무국적 세계관·실존 브랜드 배제(§8-7).

### 0.4 표기 규약

- **설계 결정:** — 원 요구가 모호하거나 선택지가 갈리는 지점의 확정. 근거 1줄 이상.
- **[game-design 개정 필요]** — 게임 규칙 변경을 요구하는 제안. 본 문서는 규칙을 신설하지 않고 안건으로만 제기하며, 승인 전까지 해당 상품은 **보류**한다.
- 구체 수치(다이아 개수·가격·보너스율·캡)는 **§balance 튜닝 대상 기준선**이다. 본 문서는 SKU 착수가 가능한 baseline을 제시하되, 최종 값은 `balance.md`·소프트런치 실측이 확정한다.
- 통화 기준선: **KRW / USD**. 지역 확장은 §4.4.

## 1. 수익화 철학·포지셔닝

### 1.1 "존중하는 수익화" 5원칙

미드코어 F2P에서 장기 리텐션과 수익을 양립시키는 유일한 길은 **플레이어를 존중하는 것**이라는 전제에서 출발한다.

1. **결제는 승리가 아니라 시간·편의·자기표현·응원을 산다.** 다이아로 살 수 있는 것은 (a) 내 시간, (b) 편의, (c) 코스메틱(자기표현), (d) 구독/서포터(응원)뿐이다. 권력·전투력·타인 대비 우위는 **판매 목록에 없다.**
2. **핵심 경제는 결제로부터 봉인되어 있다**(§1.2). 자금·골드·명성·직원 성장은 어떤 결제로도 직접 살 수 없다 — 이것이 비-P2W의 **구조적 보증**이다.
3. **정직한 정보.** 모든 가격은 실화폐 환산이 명확히 보이고, 소비성 재화 잔액·오퍼 조건·자동갱신은 숨기지 않는다(§9.3).
4. **압박하지 않는다.** 리아를 포함한 어떤 화자도 결제를 조르지 않는다(narrative §8-5). 상점은 플레이어가 **찾아오는** 곳이지 밀어붙이는 팝업이 아니다.
5. **무과금을 벌하지 않는다.** 무과금 플레이어도 완주(§11.2)까지 온전히 도달하며(게임오버 없음과 정합), 결제는 그 여정을 **더 빠르고 더 예쁘게** 만들 뿐이다.

### 1.2 폐쇄 경제 = 구조적 비-P2W 보증 (핵심 논거)

`game-design.md`의 경제는 의도적으로 **닫혀 있다**: 자금 유입 2종(프로젝트 보상·시드)·유출 8종은 닫힌 목록이고(§5.3~5.4), 골드는 청산↔설립 루프 하나로 봉인되며(§10.2), 회사 간 이전·골드 주입은 전면 금지다(§5.9). 명성은 프로젝트로만, 직원은 채용·훈련·XP로만 자란다.

**설계 결정: 다이아는 이 닫힌 경제에 절대 진입하지 않는다.** 다이아는 폐쇄 경제 **바깥**의 병렬 레이어 — **시간·편의·코스메틱** — 에서만 작동한다. 근거: 결제가 자금/골드/명성/직원 중 하나라도 직접 살 수 있게 되는 순간 비-P2W가 무너지고, 동시에 게임의 정합성(파산 긴장·청산 판단·명성 재등반)도 무너진다. 경제를 봉인해 둔 원 설계가 곧 최고의 비-P2W 장치이므로, 수익화는 그 봉인을 **깨지 않는 것**을 제1 규율로 삼는다.

이 원칙의 강한 따름정리: **완주 소요 일수(사실상의 스코어, §11.2)는 게임 내 일수 기준**이므로, 실화폐로 산 시간 단축(§3.3)은 **실시간**만 압축할 뿐 게임 내 일수를 줄이지 않는다 → 시간 단축 상품은 (post-MVP 리더보드가 생겨도) 스코어에 이득을 주지 않는다. 오히려 시간 단축은 자율(α_auto 페널티) 구간을 진행시키므로 게임 효율상 미세하게 **불리**할 수 있다. 결제가 성능 우위로 전환되지 않음이 이중으로 보증된다.

### 1.3 포지셔닝 — 넓은 전환 우선(broad-based), 고래 착취 아님

- **미드코어 F2P**: 캐주얼보다 깊고 하드코어보다 접근성 있는 P3 좌표. 수익 구조는 **소수 고래 착취**가 아니라 **넓은 소과금 + 구독 침투**로 설계한다.
- **의도된 트레이드오프:** 판매 목록에 성능이 없으므로 **고과금 상한(whale ceiling)은 낮다.** 이를 (a) 코스메틱 컬렉션의 폭·시즌 로테이션, (b) 구독·시즌 패스의 반복 결제, (c) 넓은 전환율로 보상한다. 낮은 고래 상한은 결함이 아니라 비-P2W 무결성·리텐션·공정성과 맞바꾼 **의도된 선택**이다.
- **리텐션이 LTV의 엔진:** 이 게임의 리텐션은 방치·재기 루프(§11.6)다. FOMO로 단기 지출을 짜내면 리텐션(=LTV의 근본)을 태운다. 따라서 프로모션은 **정직한 케이던스**(시즌·번들)로만 굴린다(§6).

### 1.4 목표 KPI 레버 개괄 (상세 지표·목표치는 §liveops-analytics 소관)

본 문서는 **레버**만 다룬다. 텔레메트리·목표 수치·대시보드는 `liveops-analytics.md`가 소유한다.

## 2. 재화 아키텍처

### 2.1 다이아 — 정의 (규약 2.1)

- **다이아(Diamond)** 는 **실화폐로 구매하거나 무료로 지급받는 프리미엄 결제 재화**다. 게임플레이 자원(자금·골드·명성·XP·컨디션·충성도)이 **아니다.**
- 다이아는 일 처리·월말 정산·프로젝트·직원·회사 등 **시뮬레이션 어디에도 참여하지 않는다.** 다이아 소비는 상점/오퍼 레이어에서 발생하며, 게임 상태에 개입하는 유일한 예외(지원자 풀 즉시 갱신)는 개정 안건으로 별도 처리한다(§3.4).
- 회계 유형: **소비성(consumable) 재화.** 계정 귀속(회사 아님), 서버 권위(server-authoritative) 원장으로 관리한다(§8.2).
- **설계 결정: 다이아 표기·아이콘은 게임 내 6종 자원과 시각적으로 확연히 구분한다.** 근거: 결제 재화와 게임 자원의 혼동은 오인 결제·다크패턴 신고의 근원이다. 다이아는 항상 "실화폐로 산/받은 것"으로 읽혀야 한다(§9.3).

### 2.2 재화 경계 매트릭스 (교환·주입 규칙)

| 방향 | 허용? | 규칙/근거 |
|---|---|---|
| 실화폐 → 다이아 | **허용** | IAP 팩(§3.1). 결제의 정문 |
| 무료 지급 → 다이아 | **허용** | 메타 트랙·광고·패스(§2.3) |
| 다이아 → 코스메틱 | **허용** | 폐쇄 경제 밖 자기표현 |
| 다이아 → 시간 단축(사이클 진행) | **허용** | 폐쇄 경제 밖 편의(§3.3) |
| 다이아 → 지원자 풀 즉시 갱신 | **조건부** | 기존 레버 가속, 단 규칙 훅 필요 → **[game-design 개정 필요]**(§3.4) |
| 다이아 → 자금(₩) | **금지** | §5.9 회사 자금 주입 금지. 비-P2W 정면 위반 |
| 다이아 → 골드 | **금지** | §2.5/§10.2 골드 유입 = 청산 유일. 새 유입 경로 신설 |
| 다이아 → 명성/XP/직원 강화 | **금지** | 게임플레이 자원 직접 구매 = P2W |
| 다이아 → 슬롯 해금 | **금지** | §10.3 등급 문턱, 구매 불가 |
| 다이아 → 승급비/개설비/계약금/훈련비 대납 | **금지** | 자금 주입의 우회. §5.4 유출 목록 밖 |
| 골드 ↔ 다이아 (양방향) | **금지** | 경영자 재화(골드)와 결제 재화(다이아)는 서로 교환되지 않는다 |

이 표가 **비-P2W의 실행 명세**다. 오른쪽 절반(금지)이 곧 폐쇄 경제의 봉인선이다.

### 2.3 다이아 획득 (유료 + 무료 지급 지점)

**유료 (매출):**
- 다이아 팩 7티어(§3.1), 첫결제 2배 보너스(§3.2), 스타터 팩 동봉분(§3.2), 구독 일일 지급(§3.5), 시즌 패스 프리미엄 트랙(§3.6).

**무료 지급 (페이싱 — 무과금 리텐션·전환 온램프):**
- **일일 로그인 소액 지급**(예: 첫 접속 보너스, 캘린더). 연속 보너스는 두되 **끊겨도 벌하지 않는**(리셋 페널티 없는) 완만한 곡선(narrative §8-2 정합).
- **시즌 목표(무료 트랙)·업적** 완료 시 지급(§2.5의 메타 트랙).
- **리워드 광고**(옵트인, 일일 캡, §5).
- **무료 배틀패스 트랙**의 다이아 노드(§3.6).
- **온보딩 소액 지급**: M1~M6 진행 중 상점을 한 번 자연스럽게 접하도록, 첫 코스메틱을 살 수 있는 소액을 **온보딩 메타 이벤트**로 지급(마일스톤 자체 보상 아님 — §2.5).

|---|---|---|---|
| S-1 | **코스메틱** (오피스 스킨·리아 테마/보이스·장식 호칭·엠블럼·카드 프레임·UI 테마) | 자기표현 | §3.7 |
| S-2 | **사이클 즉시 진행권** (전 회사 동시, 오프라인 진행 압축) | 시간 단축 | §3.3 |
| S-3 | **시즌 패스 프리미엄 즉시 해금 / 티어 스킵** | 편의 | §3.6 |
| S-4 | **지원자 풀 즉시 갱신** *(개정 승인 시)* | 기존 레버 가속 | §3.4 |

- 구독·광고 제거·스타터 팩은 **실화폐 직접 결제**를 권장(다이아 소비 아님)하여 다이아 소비 생태계를 단순·투명하게 유지한다.
- **설계 결정: 다이아 소비처를 위 4종으로 좁게 닫는다.** 근거: 소비처를 넓힐수록 폐쇄 경제와의 접점 위험이 커진다. 좁은 소비처는 (a) 비-P2W 감사(audit)를 쉽게 하고 (b) 다이아 가치를 명료하게 한다.

### 2.5 무료 다이아 페이싱 — 마일스톤 무보상 원칙 보존 (설계 결정)

**설계 결정: 무료 다이아는 game-design 마일스톤(M1~M15, 무보상 불가침 §11.5)이 아니라 별도의 "수익화 메타 트랙"(로그인·시즌 목표·업적)에서 지급한다.**

근거:
- game-design §11.5는 마일스톤이 **자원 보상을 주지 않는다**고 확정했다(자원 획득 경로 오염 방지). narrative §0.3-8은 마일스톤을 "감정적 비트"로 규정한다.
- 다이아는 게임플레이 자원이 아니므로(규약 2.1) 엄밀히는 §11.5 위반이 아니지만, **마일스톤에 다이아를 얹으면** (a) "무보상 = 순수 감정 비트"라는 톤이 깨지고(narrative), (b) 진행 축과 수익화 축이 뒤섞여 밸런싱·톤 양쪽이 오염된다.
- 따라서 두 축을 **분리**한다: 마일스톤 = 감정·해금·기록(무보상 유지), 다이아 지급 = 로그인/시즌 목표/업적/광고라는 **독립 메타 트랙**.

**메타 트랙의 규칙적 지위:** 시즌 목표·업적 진행도(파스 포인트 등)는 **게임플레이 자원이 아니다.** 시뮬레이션(일 처리·월말 정산·프로젝트·직원·회사)에 참여하지 않고, 오직 다이아·코스메틱만 산출하며, 규약 2.1이 다이아에 부여한 "비 게임플레이 결제 레이어"에 함께 귀속된다. 따라서 §2.4-1(자원 6종 외 신설 금지)에 저촉되지 않는다 — 게임 상태를 바꾸지 않는 순수 메타 계측이다.

**[game-design 개정 필요 아님]** 확인: 메타 트랙은 game-design 규칙과 무관한 수익화 레이어이므로 규칙 개정을 요구하지 않는다. 단, 메타 트랙 목표가 **플레이 행동을 왜곡**(예: 특정 프로젝트 반복 강제)하거나 **FOMO 그라인드**를 유발하지 않도록 설계 제약을 둔다(§6.2).

## 3. 상품 카탈로그

가격·다이아 수치는 §balance 기준선(§4). 각 상품은 **가치·대상 세그먼트·SKU**를 명시한다. SKU 요약은 §10.

### 3.1 다이아 팩 (7티어)

- **가치:** 다이아 벌크 구매. 다이아 생태계의 근간.
- **대상:** 전 결제 세그먼트. 저티어 = 충동/소과금 진입, 고티어 = 고과금 벌크.
- **구성:** 티어가 오를수록 **보너스 다이아율이 단조 증가**하는 표준 곡선(§4.2). 심리적 가격점은 플랫폼 표준 티어에 정렬(§4.3).
- **회계 유형:** 소비성. 복원 대상 아님(소비성 재화 표준).

### 3.2 스타터 팩 · 첫결제 오퍼

**스타터 팩 (`pack_starter`)**
- **가치:** 신규/초기 플레이어용 1회 한정 고가치 번들. 첫 지출 문턱을 낮춘다.
- **구성(기준선):** 중티어 상당 다이아 + 오피스 스킨 1종 + 사이클 즉시 진행권 다수 — **개별 구매 대비 약 2배 가치**를 정직하게 명시.
- **대상:** 미결제 신규(전환 온램프). **1인 1회, 노출 기간 무기한**(진짜 1회성이므로 카운트다운 압박 불필요 — narrative §8-6 정합).
- **가격:** ₩5,500 / $4.99 기준선.

**첫결제 2배 보너스 (`offer_firstbuy_2x`)**
- **가치:** 아무 다이아 팩이든 **생애 첫 구매 시 다이아 2배**(1회). 업계 표준의 정직한 형태.
- **대상:** 전환 직전 세그먼트. 스타터 팩과 중복 적용 규칙은 §balance(권장: 둘 중 유리한 쪽 자동 적용, 이중 청구 없음).

### 3.3 시간 단축 — 사이클 즉시 진행권 (오프라인 진행 압축)

**핵심 설계 결정: 시간 단축은 오직 "전 회사 동시 사이클 진행"으로만 제공한다.**

- **상품:** **사이클 즉시 진행권** — 현재 시각 이후로 누적될(또는 누적된 오프라인) 진행분을 **즉시 처리**해, 전 회사에 대해 N사이클의 일 처리 5단계를 결정론적으로 앞당겨 이행한다.
- **game-design 정합 논거:**
  - §2.1은 "사이클은 전 회사에 **동시 적용**, 회사별 일시정지·배속 없음"이라 못박았다. 본 상품은 **전 회사 동시 진행**이므로 이 규칙에 정합한다(회사별·엔티티별 배속이 아님).
  - **새 자원·새 처리 단계 없음:** 기존 일 처리 5단계(§2.2)를 그대로, 더 빠르게 돌릴 뿐이다. §2.4-1·2.4-2 위반 없음.
  - P1의 **방치 플레이**는 사이클이 실시간으로 진행(오프라인 누적)됨을 이미 전제한다 — 본 상품은 그 누적을 **압축**하는 편의이지 새 규칙이 아니다. (사이클↔월클럭 바인딩·오프라인 상한 등 페이싱 수치는 §technical-architecture / §balance 소관 — §11-B.)
- **비-P2W 논거(§1.2 재확인):** 진행은 결정론적이며(흥행 롤 포함 서버 권위 — §8.2), 기다리든 스킵하든 **결과가 동일**하다. 스킵되는 사이클의 자율 부서는 α_auto 페널티가 적용된 채 굴러가므로, 시간 단축은 **직접 하달 프리미엄을 사지 못한다.** 완주 일수(스코어)는 게임 일수 기준이라 실시간 압축은 스코어 무이득(§1.2).
- **대상:** 방치 플레이 중심의 전 세그먼트. 특히 세션이 짧은 플레이어(P1)가 "돌아왔을 때 밀린 진행"을 즉시 정리하는 편의.
- **가격(기준선, §balance):** 진행권 소(小) 60 다이아 / 진행권 대(大, 묶음 할인) 200 다이아. 리워드 광고로 소형 진행권 무료 획득(§5). 구독자 일일 무료 진행권(§3.5).

**설계 결정: 개별 프로젝트 즉시 완료(인스턴트 피니시)는 상품화하지 않는다.** 근거: (a) 회사별·엔티티별 배속 금지(§2.1)의 정신에 저촉, (b) 고가치 프로젝트만 골라 가속하는 것은 시간 단축을 넘어선 결과 조작(P2W 인접), (c) 컨디션 소모·기한·품질 산정이 사이클 누적에 묶여 있어 개별 완료는 새 규칙을 요구한다. 시간 단축은 전역 사이클 진행으로만 제공한다.

### 3.4 편의 상품 — 지원자 풀 즉시 갱신 (기존 레버 가속)

- **상품:** **지원자 풀 즉시 갱신** — 월말 정산까지 기다리지 않고 회사의 공고 지원자 풀(§6.4)을 즉시 재생성한다.
- **가치:** 마음에 드는 지원자가 없을 때 **다음 갱신(월말)까지의 대기 시간**을 건너뛰는 편의.
- **[game-design 개정 필요]:** §6.4는 풀 갱신을 **월말 정산 5단계의 자동 이벤트**로만 정의한다. 플레이어가 임의 시점에 갱신을 발동하는 것은 현재 규칙에 없다. 본 상품은 다음 개정을 **전제**한다: *"§6.4에 플레이어 발동 지원자 풀 갱신을 일 처리 1단계(지시 반영)의 하위 작업으로 등재"* (새 자원·새 단계 없이 1단계 하위 작업으로 편입되므로 §2.4에 정합). **개정 승인 전까지 본 상품은 보류한다** — 본 문서는 규칙을 임의 신설하지 않는다.
- **비-P2W 가드(개정 시 필수 조건):**
  1. **갱신은 명성 기준 분포(§6.3·§6.4)로만 재롤하며, 다이아가 등급·스탯 품질을 부스트하지 않는다.** 저명성 회사가 돈을 써도 S급 확률이 오르지 않는다 → 성능이 아닌 **시간/기회**만 산다.
  2. **월내 반복 갱신 비용 체증**(예: 30 → 60 → 120 다이아, 월말 리셋)으로 고과금의 "S급 낚시(pay-to-fish)"를 억제한다.
  3. 지원자는 **전부 공개 카드**(§6.4)이고 채용에는 계약금(자금)이 든다 → 갱신 자체가 성능을 주지 않는다.
- **대상:** 특정 회사를 밀도 있게 키우는 소~고과금(포커스 운영, §10.7).
- **가격(기준선):** 위 체증 곡선, §balance.

**아웃 오브 바운드(명시적 배제):** 아래는 "편의"로 위장한 성능/우회이므로 상품화하지 않는다 — 자금·골드·명성·XP 구매, 승급비·개설비·계약금·훈련비 대납, 자율 주행 조기 해금, 슬롯 해금, α_auto 완화, 컨디션·충성도 회복 구매. 또한 **주의 배분 긴장(§10.1)을 자동화로 줄이는 매크로**(정책 자동 최적화, 결정 대행)도 배제한다 — 그 긴장이 곧 게임플레이이므로 이를 돈으로 줄이면 연성(soft) P2W가 된다. (자율 일괄 토글은 이미 무료 §9.2.)

### 3.5 구독 — 서포터 패스 (월 구독)

- **상품(`sub_supporter_monthly`):** 자동 갱신 월 구독.
- **가치(기준선, 전부 시간·편의·코스메틱·응원 범주):**
  - **일일 다이아 지급**(예: 40/일 ≈ 월 1,200 — 팩 대비 유리하되 벌크 최상위보다는 낮게).
  - **일일 무료 사이클 진행권** 1개(§3.3).
  - **무광고 자동 수령**: 리워드 광고를 보지 않아도 광고 등가 소액 보상 자동 지급(§5).
  - **오프라인 진행 수령 상한 확대**(편의 — 자주 못 여는 플레이어를 위한 방치 상한 상향, 성능 아님).
  - **구독 전용 코스메틱**(월 로테이션 프레임/엠블럼 — 컬렉션 유인).
- **비-P2W 확인:** 모든 혜택이 시간·편의·코스메틱이며, 게임플레이 자원·해금·성능은 없다. 구독 다이아도 소비처는 §2.4로 닫혀 있다.
- **대상:** 게임을 꾸준히 하는 소~중과금(가장 안정적인 LTV·리텐션 세그먼트).
- **가격:** ₩11,000 / $9.99 기준선. **회계 유형:** 자동 갱신 구독(복원·해지 표준, §8.3).
- **윤리:** 자동 갱신·해지 방법을 결제 전 명시(§9.3). 미결제 전환 방지 다크패턴 금지(무료 체험 함정 없음).

### 3.6 배틀패스 — 시즌 패스

- **상품(`pass_season`):** 시즌(기준선 6주) 단위 프리미엄 트랙.
- **구조:** **무료 트랙 + 프리미엄 트랙 병존.** 무료 트랙은 다이아·소액 보상을 주어 무과금도 시즌에 참여한다. 프리미엄 트랙은 다이아 누계 + 다수 코스메틱 + 사이클 진행권 등으로 구성.
- **진행:** 시즌 목표(자연스러운 플레이로 달성 가능한 주간/일간 과제)로 파스 포인트 획득. **파스 포인트는 게임플레이 자원이 아니다**(§2.5 메타 트랙).
- **비-P2W 확인:** 프리미엄 보상 = 다이아 + 코스메틱 + 시간 편의뿐. **성능·해금·게임플레이 자원 없음.** 프리미엄 즉시 해금/티어 스킵을 다이아로 판매(§2.4 S-3)하되, 이는 시간 절약이지 성능이 아니다.
- **윤리(narrative §8 정합):**
  - 시즌 마감은 **정직한 실제 날짜**로 명시 — 조작적 카운트다운·거짓 희소성 금지(§8-6).
  - 시즌 목표는 **넉넉한 완료 여유**를 두고, 미완료가 "손해"로 프레이밍되지 않는다(§8-2).
  - 로그인 스트릭 **끊김 처벌 없음.**
  - **[열린 질문]** 미획득 시즌 코스메틱의 사후 재획득(레거시 상점) 정책 — 절대 희소성 vs 재판매의 트레이드오프(§열린 질문).
- **대상:** 반복 결제 의향이 있는 소~고과금 + 무료 트랙으로 전 무과금(참여·전환 온램프).
- **가격:** 프리미엄 ₩12,000 / $9.99 기준선/시즌. **회계 유형:** 시즌별 비소비성 SKU(또는 소비성 — 플랫폼 정책에 맞춰 §8.3 확정).
- **경계:** 시즌 **콘텐츠·스케줄·A/B**는 §liveops-analytics 소관. 본 문서는 패스의 **유형·보상 범주·윤리 규칙**만 정의한다.

### 3.7 코스메틱 (§art-direction · §narrative-tone 연동)

자기표현 소비의 핵심. **게임플레이 영향 0.** 에셋 제작은 §art, 톤·네이밍은 §narrative 소관이며, **판매·가격·번들은 본 문서**가 소유한다.

| 카테고리 | 예시 | 연동 | 가격대(다이아, 기준선) |
|---|---|---|---|
| **오피스 스킨** | 업종 무드(무역/게임개발/화장품 §narrative 4.3)에 맞춘 사무실 배경·데코 | §art 업종 무드·색감 | 500~900 |
| **리아 테마/보이스 팩** | 보좌관 리아(§narrative 4.1)의 대체 비주얼 테마·보이스 스킨 | §narrative 리아 캐스팅(열린 질문)·§audio | 700~1,200 |
| **장식 호칭** | 순수 플레이버 호칭(진행성 호칭과 별개) | §narrative 톤 | 50~150 |
| **엠블럼/로고 장식** | 회사 엠블럼·프레임 장식(무국적·비실존 §narrative 2.1) | §art | 100~400 |
| **직원 카드 프레임** | 카드 테두리·배경(스탯 불변, 존엄 유지 §narrative 4.2) | §art | 200~400 |
| **UI 테마** | 대시보드 컬러 테마 | §art·§ux | 200~400 |

- **설계 결정: 진행성 호칭(대표님→회장님, §narrative 1.2)은 판매하지 않는다.** 근거: 이는 **보유 회사 최고 등급에 연동된 무료 진행 보상**이다. 판매 호칭은 진행과 무관한 순수 플레이버 호칭으로 한정해 "결제로 지위를 산다"는 오해를 차단한다.
- **가드레일(narrative §3.3·§8):** 코스메틱은 실존 브랜드·국가·인물·밈을 쓰지 않고(무국적 세계관 §2.1), 직원을 소모품/희화화하지 않으며, 차별·선정성을 담지 않는다. 등급을 "인간 가치"로 표현하는 코스메틱(예: 등급 조롱 프레임) 금지.
- **판매 형태:** 다이아 직접 구매 + 실화폐 번들(스킨+다이아) + 시즌 로테이션. **회계 유형:** 비소비성(복원 대상, §8.3).
- **대상:** 전 세그먼트(무과금도 무료 다이아로 일부 접근). 컬렉션 성향 고과금의 상한을 여기서 확보(§1.3).

### 3.8 광고 제거권

- **맥락:** 본 게임의 광고는 **옵트인 리워드 광고 전용**(전면·강제 광고 없음 — §5). 따라서 전통적 "제거할 강제 광고"가 거의 없어, 표준 remove-ads의 가치가 낮다.
- **설계 결정: 광고 제거권을 "무광고 서포터(`noads`)"로 재정의한다.** 구성: (a) 리워드 광고 **진입점 UI 숨김**(광고를 아예 보고 싶지 않은 플레이어 존중), (b) **리워드 등가 일일 소액 보상 자동 지급**(광고 없이도 무과금 온램프 혜택 유지). 근거: 옵트인 모델에서 "광고를 없앤다"보다 "광고 없이도 그 혜택을 받는다"가 실질 가치다.
- **대상:** 광고를 선호하지 않는 소과금.
- **가격:** ₩5,500 / $4.99 기준선. **회계 유형:** 비소비성(복원 대상). **구독(§3.5)에 포함**되므로 구독자에게 별도 판매하지 않는다(중복 방지).

## 5. 광고 (선택적 보조)

### 5.1 원칙

- **설계 결정: 옵트인 리워드 광고만 사용하고, 전면(interstitial)·강제·배너 광고는 배제한다.** 근거: P3 밝고 존중하는 톤 + narrative §8(압박·강박 금지)과 강제 광고는 상충한다. 광고는 **무과금 리텐션 보조와 소프트 온램프**이지 매출의 축이 아니다.
- **코어 게임플레이를 광고로 게이팅하지 않는다**(진행·수익·해금을 광고 시청에 묶지 않음). 광고는 항상 "봐도 되고 안 봐도 되는" 선택.

### 5.2 리워드 광고 지점·보상 후보 (전부 옵트인)

| 지점 | 보상(기준선) | 근거 |
|---|---|---|
| 오프라인 복귀 요약 화면 | **사이클 진행권 소 1개**(광고 시청 시) | 방치 편의의 무과금 경로(§3.3) |
| 일일 무료 보상 | **소액 다이아**(일일 캡) | 무과금 다이아 온램프(§2.3) |
| 시즌 목표 부스트(선택) | 파스 포인트 소액(캡) | 무료 트랙 참여 촉진(§3.6) |

- **금지 지점:** 프로젝트 완료 강제 시청, 결산 리포트 게이팅, 알림성 강제 노출. 광고는 **플레이어가 버튼을 누를 때만** 재생.

### 5.3 IAP 카니발라이제이션 관리

- **역할 분리:** 리워드 광고는 **시간(사이클 진행권)·소액 다이아**를 주고, IAP는 **벌크 다이아·코스메틱·구독·시즌 패스**를 준다. 광고로는 벌크·코스메틱·성능을 주지 않는다.
- **일일 캡:** 광고 보상(다이아·진행권)에 일일 상한을 두어 IAP 벌크 수요를 잠식하지 않게 한다(캡 수치 §balance).
- **구독 흡수:** 광고 등가 보상은 구독(§3.5)·무광고 서포터(§3.8)에 자동 포함 → 광고를 싫어하는 플레이어의 결제 경로를 연다(카니발이 아니라 세그먼트 분리).
- **경계:** 광고 네트워크·eCPM·게재 빈도 최적화·A/B는 §liveops-analytics/§technical-architecture. 본 문서는 **지점·보상 범주·옵트인 원칙**만 정의한다.

## 6. 오퍼·프로모션 구조

### 6.1 오퍼 유형 카탈로그

| 오퍼 | 형태 | 윤리 요구 |
|---|---|---|
| **첫결제 2배** | 1회 한정, 전 팩 적용(§3.2) | 조건 명시, 이중 청구 없음 |
| **스타터 팩** | 1회 한정 고가치 번들(§3.2) | 진짜 1회성 → 카운트다운 압박 불요 |
| **가치 번들** | 다이아+코스메틱+진행권 묶음, 개별 대비 정직한 할인 | 실제 개별가 대비 할인율 명시 |
| **시즌 세일** | 코스메틱·팩 보너스 이벤트(정직한 케이던스) | 실제 기간 명시, 거짓 희소성 금지 |
| **복귀 환영 오퍼** | 장기 미접속 후 복귀 시 소액 선물/할인 | 죄책감 없이 환영(narrative §8-1: "오셨네요") |

### 6.2 윤리적 설계 (가드레일 — narrative §8 정본 준수)

- **거짓 희소성·조작적 카운트다운 금지**(§8-6): "재고 3개 남음", 가짜 타이머 금지. 한정 오퍼의 기간은 **실제 종료일**만 표기.
- **FOMO·긴급 과장 금지**(§8-2): "지금 안 사면 손해" 카피 금지. 미구매가 손실로 프레이밍되지 않는다.
- **죄책감 금지**(§8-1): 방치·미결제·복귀를 "당신 탓"으로 몰지 않는다.
- **결제 압박 금지**(§8-5): 리아 등 어떤 화자도 결제를 조르지 않는다. 오퍼는 **정보 제공**이지 강권이 아니다.
- **다크패턴 금지**(§9.3): 미끼 상술, 통화 난독화, 강제 연속결제, 숨은 자동갱신 금지.
- **메타 트랙 행동 왜곡 금지**(§2.5): 시즌 목표가 특정 프로젝트 반복·비합리 플레이를 강제하지 않는다.

### 6.3 세일 정책

- 코스메틱·팩 보너스 세일은 **예측 가능한 시즌 케이던스**로만(상시 할인은 정가 신뢰를 무너뜨림).
- 구독·시즌 패스 정가는 유지하고, 세일은 **다이아 팩 보너스 증량·코스메틱 번들**로 표현.
- 개인화 할인(세그먼트 타깃)은 §liveops 소관이되, **동일 상품을 세그먼트별로 다른 정가로 파는 가격 차별은 하지 않는다**(신뢰·규제 리스크). 세일은 한시적·투명하게.

### 6.4 라이브 오퍼 경계 (§liveops-analytics)

- 본 문서 = **오퍼의 유형·구성·윤리 규칙·정가 구조**(정본).
- §liveops = **언제/누구에게**(스케줄·타깃팅·캘린더·A/B·개인화 트리거).
- 두 문서의 접점: 본 문서가 정의한 오퍼 카탈로그·가드레일을 §liveops가 준수하며 운영한다.

## 7. 세그먼트·LTV 레버

### 7.1 세그먼트별 경험 설계

| 세그먼트 | 경험 설계 | 결제 대상 상품 |
|---|---|---|
| **무과금** | 완주까지 온전한 여정(§7.2). 무료 다이아(로그인·시즌 무료 트랙·업적·광고)로 코스메틱 일부·시간 편의 접근. 벽 없음 | — (광고·무료 트랙) |
| **소과금(minnow)** | 첫 지출은 스타터/구독. 시간 편의 + 무광고 + 시즌 참여로 "쾌적한 플레이"를 산다 | 스타터·구독·시즌 패스·진행권 |
| **고과금(whale)** | 코스메틱 컬렉션·전 시즌 패스·구독·빈번한 시간 단축. **성능이 아닌 폭·자기표현·응원**에 지출 | 코스메틱 다수·벌크 팩·전 상품 |

- **의도된 고래 상한(§1.3):** 성능이 없으므로 whale ARPU 상한은 낮다. 이를 코스메틱 폭·시즌 로테이션·구독 지속으로 보상하되, 상한을 억지로 높이려 성능을 팔지 않는다.

### 7.2 무과금 완주 보증 (게임오버 없음과 정합)

- **설계 결정: 무과금 플레이어는 어떤 결제 없이도 완주(§11.2)에 도달할 수 있어야 한다.** 근거: game-design §5.6·§11.6의 "게임오버 없음 + 데드락 없음" 철학. 결제는 완주를 **더 빠르고 예쁘게** 만들 뿐, 완주의 **필요조건이 아니다.**
- 보증 요건: (a) 시간 단축은 실시간만 압축(게임 진행의 필수 아님, §3.3), (b) 다이아 소비처에 진행 필수재 없음(§2.4), (c) 광고·무료 트랙만으로도 정상 페이싱, (d) 어떤 상품도 폐쇄 경제(자금·명성·해금)에 개입하지 않음(§1.2).

### 7.3 전환 퍼널 (설치 → 첫결제 → 재결제)

| 단계 | 레버 | 시점·톤 |
|---|---|---|
| **설치 → 활성** | 온보딩 무료 다이아 + 첫 코스메틱 체험(§2.3) | M1~M6, 압박 없이 상점을 한 번 자연 노출 |
| **활성 → 첫결제** | 스타터 팩 + 첫결제 2배(§3.2) | **감정적 하이 직후**(첫 승급·첫 히트작 등) 자연 노출 — 위기·죄책감 순간 아님(narrative §8) |
| **첫결제 → 재결제** | 구독·시즌 패스 케이던스(§3.5~3.6) | 반복 가치의 리듬(월/시즌), 강권 없음 |
| **재결제 → 지속** | 코스메틱 로테이션·시즌 신규(§3.7, §liveops) | 컬렉션·자기표현의 지속 유인 |

- **첫결제 트리거 원칙:** 성취의 봉우리(narrative §1.3 감정 곡선)에서 제안하고, 밸리(위기·부실)에서는 **제안하지 않는다**(죄책감 결제 유도 금지, §8-1).

## 8. 스토어 UX 훅 (§ux-design 상세 소관)

화면 레이아웃·플로우 상세는 `ux-design.md` 소관. 본 문서는 **수익화 측 요구사항**만 명시한다.

### 8.1 상점 진입·구성 요구

- **진입점:** 상시 접근 가능하되 **비침투적**(고정 상점 아이콘). 반복 팝업·강제 인터셉트 금지(§6.2, narrative §8-5).
- **탭 구성(요구):** 다이아 팩 / 오퍼(스타터·번들) / 코스메틱 / 구독 / 시즌 패스. 각 탭은 가격·구성·실화폐 환산이 명확히 보여야 한다(§9.3).
- **소비성 잔액 상시 표시:** 다이아 보유량·획득 출처가 투명해야 한다.
- **오프라인 복귀 화면:** 방치 요약 + 옵트인 광고/진행권 제안(강제 아님, §5.2).

### 8.2 결제 플로우·영수증·복원

- **결제:** 플랫폼 IAP(App Store StoreKit / Google Play Billing)만 사용. 자체 결제 우회 금지(플랫폼 정책).
- **영수증 검증:** **서버 권위 검증**(server-side receipt validation). 다이아·비소비성·구독 부여는 서버가 확정하며, 클라이언트 신뢰 금지(치트·환불 남용 방지).
- **소비성/비소비성 구분:** 다이아 = 소비성(복원 대상 아님). 코스메틱·무광고 = 비소비성(**복원 지원 필수**). 구독 = 자동 갱신(복원·상태 동기화).
- **복원(Restore Purchases):** 비소비성·구독은 기기 변경·재설치 시 복원 제공(플랫폼 요구).
- **시간 단축의 서버 결정성:** 사이클 진행권 처리는 서버 권위·시드 고정으로 결정론 유지 → 흥행 롤(§8.7 game-design) 재굴림 등 결과 조작 불가(§3.3 비-P2W 조건).

### 8.3 스토어 정책 준수 체크리스트 (Apple / Google / KR)

- **Apple App Store:** 디지털 재화는 IAP로만(3.1.1). 자동 갱신 구독 고지·관리 링크(3.1.2). 확률형 없음 → 3.1.1(x) 확률 공시 **해당 없음**. 가격·기간 명확 표기.
- **Google Play:** Play Billing 사용, 구독 갱신·해지 명시. 확률형 아이템 정책 **해당 없음**.
- **KR 규제:** 게임산업진흥법 확률형 정보공개 의무 → 확률형 미사용(§9.1)이므로 **적용 대상 아님**(단, 향후 도입 시 확률 공시 의무 발생 — §9.1). 미성년자 결제 한도·법정대리인 동의·청약철회(전자상거래법) 준수.
- **공통:** 실화폐 환산 명시, 자동갱신 사전 고지, 오인 결제 방지 확인 단계, 환불·복원 경로 제공.

## 9. 윤리·규제

### 9.1 확률형(가챠) 미사용 결정

- **설계 결정: 확률형 상품(가챠)을 사용하지 않는다.**
- **근거(게임 규칙과의 정합):** 직원 채용은 game-design §6.4상 지원자 카드가 **등급·초기 스탯·리더십·계약금·기본급 전부 공개**이며, 비용은 **계약금(자금)** 이다 → 채용은 확률형이 아니다. 다이아는 어떤 **무작위 결과**도 사지 않는다(§2.4 소비처 전부 결정적). 게임 내 유일한 대형 RNG인 흥행 롤(§12.3)은 **게임플레이 메커닉이지 판매 상품이 아니다.**
- **결과:** 확률 공시·루트박스 규제의 상당 부분이 **구조적으로 비해당**. 이는 규제 리스크·신뢰 양면의 강점이다.
- **[향후 도입 시 조건]** 만약 확률형 요소(예: 랜덤 코스메틱 박스)를 검토한다면, 그 즉시 (a) 확률 전면 공시(KR 게임산업진흥법·플랫폼 정책), (b) 청소년 보호 강화, (c) 환불 정책 정비가 **선행 조건**이다. 본 문서는 MVP에서 **도입하지 않을 것을 권고**한다(비-P2W·존중 포지셔닝과의 정합 우선).

### 9.2 청소년 보호·환불

- 플랫폼 부모 통제·결제 한도·본인확인 흐름 준수. KR 미성년자 결제 시 법정대리인 동의·청약철회 보장.
- 오인·미성년 결제 환불: 플랫폼 표준 + 법정 청약철회 기간 준수. 소비성(다이아) 미사용분 환불 처리 정책 정비.
- 결제 확인 단계(더블 컨펌)로 우발 결제 방지.

### 9.3 다크패턴 배제 체크리스트

| 항목 | 규칙 |
|---|---|
| 통화 난독화 | 다이아↔실화폐 환산·가격을 항상 명확히. 다이아를 게임 자원처럼 위장 금지(§2.1) |
| 가짜 타이머·희소성 | 거짓 카운트다운·재고 조작 금지(§6.2, narrative §8-6) |

## 11. 게임 규칙 개정 안건 (game-design 개정 필요 / 의존성)

본 문서는 규칙을 임의 신설하지 않았다. 아래는 **개정 안건** 또는 **타 문서 의존성**이다.

- **[A. game-design 개정 필요 — 경미]** §6.4에 **"플레이어 발동 지원자 풀 갱신"을 일 처리 1단계(지시 반영)의 하위 작업**으로 등재. 새 자원·새 단계 없이 1단계 하위 작업으로 편입되므로 §2.4 프레임 내. 승인 시 `refresh_pool` 출시(§3.4 비-P2W 가드 필수). **미승인 시 상품 폐기.**
- **[B. 의존성 — §technical-architecture / §balance (game-design 개정 아님)]** 사이클↔월클럭 바인딩(1사이클 = 실시간 얼마), 오프라인 진행 누적·상한 모델. game-design은 기술·밸런싱 수치를 범위 밖으로 두므로(§1.3) 이는 규칙 개정이 아니다. **단, 설계 리뷰가 "실시간 사이클 진행"이 §2.1의 턴제·플레이어 페이스 의도와 상충한다고 판단하면 그때 game-design 개정 안건으로 격상**(§열린 질문).
- **[C. 명시적 배제 — 도입하지 않기로 결정]** 다이아→자금 주입, 다이아→골드 판매, 슬롯 판매, 성능(명성/XP/직원)·해금·α_auto 구매, 개별 프로젝트 인스턴트 피니시, 결정 대행 매크로. 전부 §0.3 불변식·비-P2W·주의 배분 긴장(§10.1) 위반. **개정으로도 도입 권고하지 않음.**
- **[D. 타 문서 연동]** 코스메틱 에셋 = §art-direction / §narrative-tone(리아 캐스팅·업종 무드·톤). 상점 화면·플로우 = §ux-design. 지역 가격 매핑·통화 포맷 = §accessibility-localization. KPI 목표·라이브 오퍼 스케줄·광고 최적화 = §liveops-analytics. 영수증 검증·서버 권위·플랫폼 SDK = §technical-architecture.

## 열린 질문

수익화 확정을 위해 밸런싱·소프트런치·타 파트와 함께 답할 미결 사항.

1. **사이클↔월클럭 페이싱** — 1사이클의 실시간 길이, 오프라인 진행 상한, "밀린 진행"의 규모. 시간 단축 상품의 체감 가치·가격을 이것이 결정한다(§11-B). 실시간 진행이 §2.1 턴제 의도와 상충하는지 설계 리뷰 필요.
2. **지원자 풀 즉시 갱신의 개정 채택 여부와 낚시 억제 강도** — §3.4 개정을 채택할지, 월내 체증 곡선과 캡이 고과금 S급 낚시를 충분히 억제하는지(명성 게이팅만으로 부족한지).
3. **다이아 팩 보너스 곡선·소비처 가격의 실측 튜닝** — §4.2·§4.5 기준선의 전환율·ARPPU 검증(소프트런치).
4. **구독 vs 시즌 패스의 카니발라이제이션** — 둘의 가치 중첩(다이아·진행권·코스메틱)이 서로를 잠식하는지, 번들/차별화 필요 여부.
5. **시즌 코스메틱의 사후 재획득 정책** — 절대 희소(레거시 미판매) vs 레거시 상점 재판매의 신뢰·매출 트레이드오프(§3.6).
6. **whale 상한 보상의 충분성** — 성능 미판매로 낮아진 고과금 상한을 코스메틱 폭·시즌 로테이션이 충분히 메우는지, 매출 목표와의 정합(§1.3, §liveops와 공동).
7. **리워드 광고 보상 캡** — IAP 잠식 없이 무과금 온램프를 유지하는 일일 캡 수치(§5.3).
8. **무광고 서포터의 독립 SKU 유지 여부** — 구독에 흡수되므로 별도 `noads` SKU의 실효 수요가 있는지(§3.8).
9. **지역 가격·결제 채널(CN 확장)** — 판호·제3자 스토어·현지 결제 이슈(§4.4, §accessibility-localization·§production 연동).
10. **다이아 무료 지급 총량의 밸런싱 영향** — 무과금 다이아 유입(로그인+시즌+광고+온보딩)이 코스메틱·시간 편의의 결제 유인을 과도하게 잠식하지 않는지(§2.3).
11. **골드 후반 잉여와 다이아의 관계** — game-design §15-11(후반 골드 무의미 축적)에 대해, 수익화가 **골드를 다이아로 연결하지 않기로** 확정(§2.2)했으므로, 골드 싱크 문제는 game-design/§balance가 독립적으로 해결해야 함을 확인.
