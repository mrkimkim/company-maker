> **문서 지위.** `README.md` 규약 2.2에 따라 **밸런스 수치의 정본**은 본 문서다. 본 문서는 `mechanics-spec.md`(§7 함수 라이브러리)가 확정한 **함수 형태를 바꾸지 않고 계수·값만 채운다.** `game-design.md`(시스템 정본)의 규칙과 §5.8 경제 가드레일에 모순되지 않아야 한다.
>
> **⚠ 전체가 "플레이테스트 전 1차안"이다.** 아래 모든 수치는 관계식·가드레일·페이싱 목표로부터 역산한 **시작점**이며, 소프트런치 텔레메트리(§liveops-analytics)로 교정 대상이다. 각 표의 값은 스프레드시트로 옮겨 즉시 튜닝 착수할 수 있도록 구체 수로 제시한다.
>
> **인용:** `[GD §x]` = game-design.md, `[MS §x]` = mechanics-spec.md. 통화는 정수 ₩. 고정소수 스케일 `FP = 1,000,000` [MS §2.3] — 본 문서는 스칼라를 사람이 읽는 실수(예: `0.72`)로 적고, 구현 시 `×FP`.

## 0. 밸런스 목표·철학·튜닝 우선순위

### 0.1 목표 (플레이 경험 타깃)

| 지표 | 타깃 (1차안) | 근거 |
|---|---|---|
| 활성 세션 길이 | **1~5분** + 자율 방치 [README P1] | 모바일 세로·한손 조작 |
| 첫 회사 소기업 승급 | 게임 내 **~월 4** | 창업기 학습 완료 시점 |
| 자율 주행 해금 | 소기업 승급과 동시 (~월 4) | [GD §11.4] 소기업 게이트 |
| 첫 중기업(슬롯 2) | ~월 10 | 2호 회사 진입 |
| 첫 그룹(5등급) | ~월 30 | 1개 업종 제패 |
| **완주**(전 3업종 그룹 이력) | 게임 내 **~월 75** ≈ 활성 플레이 **25~40시간** | 소프트 엔딩, 사실상 스코어 [GD §11.2] |
| 무과금 완주 | **항상 가능**(게임오버 없음) | [GD §5.6, §11.6] 데드락 부재 |

### 0.2 철학

1. **양의 마진은 "적정 편성"에서 성립한다** — `E_max`를 꽉 채운 과편성이 아니라 등급에 걸맞은 편성 기준([GD §5.8-1]). 과편성은 플레이어의 실수로 처벌한다.
2. **자율은 느린 선택이지 파산하는 선택이 아니다** — `α_auto`는 성장 속도를 깎되 생존선은 넘지 않는다([GD §5.8-2]).
3. **난이도 곡선은 완만한 창업기 → 넓어지는 분산** — 초반은 실패 비용이 작은 무역, 후반은 흥행 롤·다회사 J커브로 분산 확대.
4. **게임오버 없음과의 정합** — 어떤 값도 "직원 1명 + 상비 의뢰 → 양의 현금 유입"을 깨지 않는다([GD §11.6]).

### 0.3 튜닝 우선순위 (가장 민감한 것부터)

| 순위 | 레버 | 파급 |
|---|---|---|
| 1 | `α_auto` | 자율 생존·직접 하달 프리미엄·명성 승급 속도 동시 결정 [GD §15-1] |
| 2 | `Cap_ref(t)` 커브 | **진척·품질 x2·과부하** 3개 서브시스템에 동시 파급 [MS §12-3] |
| 3 | `R_up(g)` / `Rep(t)` 비율 | 승급 페이싱 = 전체 진행 속도 |
| 4 | `M(t,d)` vs `Pay`·`U` | 마진율(가드레일 1·3) |
| 5 | `σ_hit`, `q(Q)` | 게임개발 분산 정체성·좌절감 [GD §15-3] |
| 6 | `γ_cash`·`γ_up` | 손절 유인 vs 수확 사이클 [GD §15-10] |

## 2. 직원 밸런스

### 2.1 스탯 스케일과 등급 대역

스탯(제작/기획/영업/리더십)은 `i32`, 대역 **1~99**. 등급 = 잠재력 대역의 공개 라벨 [GD §6.3].

| 등급 | 잠재력 대역 | 초기 주스탯 | 초기 기타스탯 | 리더십 대역 | `P(리더십≥L_min)` | 계약금·급여 배율 |
|---|---|---|---|---|---|---|
| **C** | 30–50 | 6–16 | 3–10 | 5–25 | 0.15 | ×1.0 |
| **B** | 45–68 | 12–24 | 6–15 | 12–34 | 0.35 | ×1.5 |
| **A** | 62–85 | 20–34 | 10–22 | 20–45 | 0.60 | ×2.5 |
| **S** | 80–99 | 30–46 | 16–30 | 30–58 | 0.85 | ×4.3 |

- 초기 스탯 분포: 등급 대역 내 **절단정규 근사**(중앙 편향), 잠재력은 대역 **균등** [MS §3.3].
- 창립 풀은 명성 0 분포 + **리더십≥`L_min` 1인 강제 주입**(`field_id=6`) [GD §6.4].

### 2.3 성장 — XP·레벨·훈련

| 함수 | 형태 [MS §7.4] | 계수 (1차안) |

### 2.4 리더십 → 팀 (`k`, `m`)

| 함수 | 형태 [MS §7.1] | 값 (1차안) |
|---|---|---|
| `k = f(L)` 계단 | `k_base + max{i : b_i ≤ L}` | `k_base = 2`, 경계 `b = [20, 35, 50, 65, 80]` → `k ∈ [2, 6]` |
| `m = m(L)` | `1 + κ_m·max(0, L−L_min)`, clamp | `κ_m = 0.006`/점, `m_max = 1.6` |
| `A_team` 가중 | `w_main·s_main + w_sub·s_sub` | `w_main = 1.0`, `w_sub = 0.4` (부 스탯 없는 부서 `w_sub=0`) |

- `k` 계단: L20–34→2 / 35–49→3 / 50–64→4 / 65–79→5 / 80–99→6. `f(L_min=20)=2 ≥ 1` ✓
- `m` 예: L20→1.00 / L50→1.18 / L80→1.36 / L99→1.47.

## 3. 회사/조직 밸런스

### 3.1 등급 5단계 (`T_max/E_max/D_max/U/C_up/R_up`)

`D_max`는 구조 확정(스타트업 1 / 소기업 2 / 중기업+ 3) [GD §7.1]. 나머지는 등급 단조 증가.

| 등급 g | 이름 | `T_max`(팀/부서) | `E_max`(총원) | `D_max` | `U(g)` ₩/월 | `R_up(g)` 문턱 | `C_up(→g)` ₩ |
|---|---|---|---|---|---|---|---|
| 1 | 스타트업 | 2 | 8 | 1 | 100,000 | — | — |
| 2 | 소기업 | 3 | 18 | 2 | 280,000 | **600** | 1,200,000 |
| 3 | 중기업 | 4 | 36 | 3 | 650,000 | **2,200** | 4,000,000 |
| 4 | 대기업 | 6 | 64 | 3 | 1,400,000 | **6,500** | 12,000,000 |
| 5 | 그룹 | 8 | 100 | 3 | 2,800,000 | **16,000** | 32,000,000 |

- 승급 가동률: 활성 팀 수 ≥ `θ_util(0.6) × 개설 부서 수 × T_max(g)`. 예: 소기업(2부서×3팀=6) → 활성 팀 ≥ 4 [GD §7.1].
- 부서 개설비 `D_open` = **500,000₩** (첫 부서 면제). 소기업 2번째 부서·중기업 3번째 부서 개설 시 청구.

### 3.2 `Cap_ref(t)` — 티어 기준 역량 커브 (⚠ 3중 파급)

`base`(진척 정규화)·`q_raw`의 `x2`(역량 초과율)·`overload`가 모두 이 커브에 의존 [MS §7.2, §12-3]. **최민감 커브.**

| 티어 t | `Cap_ref(t)` | `R_t` (부서 역량 게이트) |
|---|---|---|
| T1 | 35 | 25 |
| T2 | 100 | 80 |
| T3 | 230 | 190 |
| T4 | 480 | 410 |
| T5 | 900 | 800 |

- `R_t` = 부서 역량(Σ 활성 팀 `Cap_team`) 게이트 [GD §8.5]. `Cap_ref(t)` = 개별 팀 기준(진척·품질) [MS §7.2].
- 설계 의도: 창립 팀(리더 L20·주스탯 15 + 팀원 2 → `A_team≈39`, `Cap_team≈39`)은 `Cap_ref(T1)=35`를 넘겨 T1을 **여유롭게**(과부하 1.0) 수행 → 완만한 창업기.
- `overload(Cap,t) = max(1, (Cap_ref(t)/Cap_team)^q_ov)`, `q_ov = 1.0`. Cap=0.5·Cap_ref → 과부하 2.0(소모 2배·진척 절반 → 기한 실패 유도).
- `Cap_team = max(1, Cap_team)` floor (나눗셈 0 방어 DD-d).

### 3.3 명성 원장

명성은 문턱형·단조 증가, 감소 없음 [GD §7.6]. 효과 2가지: 승급 문턱(`R_up` §3.1) + 지원자 풀 품질(`GradeDist` §2.2). 획득 = 프로젝트 완료 시 `Rep(t)·r_Q·α_auto`(§4).

| `q_raw` 가중 | `w1·x1 + w2·x2 + w3·x3` | `w1(기한 여유)=0.35`, `w2(역량 초과)=0.35`, `w3(컨디션)=0.30` |
| `x2` 포화 | `z_sat` | 1.0 (역량 100% 초과 시 포화) |
| `x3` 컨디션 매핑 | `C_q0`, `C_q1` | 300, 800 |
| 품질 등급 절단 | `q_c1 < q_c2` | 미흡 <0.35 / 표준 <0.65 / 우수 ≥0.65 |
| 자금 배율 `m_Q` | 등급별 | 미흡 0.80 / 표준 1.00 / 우수 1.25 |
| 명성 배율 `r_Q` | 등급별 | 미흡 0.70 / 표준 1.00 / 우수 1.30 |
| 성과 등급 절단 `d_c*` | (게임개발) `d_c1<d_c2<d_c3` | 0.30 / 0.55 / 0.80 → 실패작/평작/성공작/히트작 |

| 실패 XP `p(x)` | `p_cap·x^q_p` | `p_cap = 0.60`, `q_p = 1.0`(선형) → 진척률 x면 XP `0.6x` 지급 |
| 꼬리 `D_tail(Q)` | Q에 증가 | 실패작 0 / 평작 20 / 성공작 40 / 히트작 70 (일) |
| 꼬리 총액 `T_total(Q)` | `R_base ×` 배수 | 실패작 0 / 평작 0.80 / 성공작 2.00 / 히트작 4.00 |
| 꼬리 가중 `ω_i` | 경과에 단조 감소, `Σ=1` | 기하 감쇠 `ω_i ∝ 0.93^i`, 최대 잉여법 정수화 |

- "티어 기준 역량 팀이 무난히 끝내면 표준이 중앙값" [GD §8.7]: 기준 팀(x2≈0, 기한 여유 x1≈0.33, 컨디션 x3≈0.6) → `q_raw ≈ 0.35·0.33 + 0.35·0 + 0.30·0.6 ≈ 0.30` → 표준 하단. 역량·컨디션 여유가 있으면 우수. ✓

## 5. 업종 경제 밸런스

### 5.1 업종별 진행·보상 배율 (§4.1 기본값 위에 곱)

| 업종 | 부서 | `D_std` 배율 | `M`/보상 특성 |
|---|---|---|---|
| **무역** | 영업/소싱/물류 | ×0.60 (최단) | 고정 계수, 저분산. `M` ×0.90 |
| **화장품** | 영업/R&D/생산 | ×1.00 (R&D만 김) | 계단(감쇠). OEM 저마진, 자사 라인 고마진 |
| **게임개발** | 영업/개발/라이브운영 | 개발부 ×1.80 (최장) | 성과 등급 스파이크 + 꼬리. `R_base = M(t,중)` |

### 5.2 무역 — 시세 `μ(g, day)`

`μ = 1 + amp(g)·Σ_j sin_fp(2π·day/period_{g,j} + phase_{g,j})` [MS §7.4]. RNG 아님, 현재값만 공개.

| 품목군 g | `amp(g)` | 주기 `period` (일) | 특성 |
|---|---|---|---|
| 생활소비재 (저티어) | 0.08 | {17, 41} | 변동폭 최소 |
| 원자재 | 0.15 | {23, 53} | 중간 |
| 전자기기 (고티어) | 0.25 | {13, 29, 61} | 변동폭 최대 |

- 트레이딩 딜(소싱부, `C₀>0`·직접 하달 전용): 매입 `C₀·μ(g,착수일)` 선불, 판매 `R_base·μ(g,완료일)`. **마진 = 판매−매입** [GD §12.2].
- 시세 중립(μ=1)에서 `R_base > C₀`(가드레일 7): 예 T1 트레이딩 딜 `C₀=120,000`, `R_base=200,000` → 중립 마진 +80,000. 유리 타이밍이면 상방, 불리해도(고위험 T5) 평균은 흑자.

### 5.3 화장품 — 라인 감쇠 `δ(n)`

`δ(n) = δ_min + (1−δ_min)·ζ^n` [MS §7.4]. `n` = 누적 완료.

| 기호 | 값 |
|---|---|
| `δ_min` (하한) | **0.35** |
| `ζ` (감쇠율) | **0.82** |
| 라인 수 | 4종(기초/색조/기능성/프리미엄), R&D 체인 순차 해금 [GD §12.4] |

- `δ` 예: n0 = 1.00 / n1 = 0.883 / n3 = 0.708 / n5 = 0.593 / n→∞ = 0.35.
- 자사 라인(`C₀`=원가, 고마진): 가드레일 7 — `δ_min`에서도 `M·δ_min − C₀ ≥ 0`. 예 T1 기초 라인 `M_line=300,000`, `C₀=90,000` → 하한 마진 = 300,000·0.35 − 90,000 = +15,000 ≥ 0 ✓. 신제품 유인은 신규 라인과의 상대 격차로.

### 5.4 게임개발 — 성과 등급 분포·꼬리

- 출시형(개발부): 완료 시 `q_raw` → 흥행 롤(`σ_hit=0.35`) → 성과 등급 4단계(§4.2). 일시 `R_base·q(Q)` + 꼬리 `T_total(Q)`.
- 성과 등급 기대 분포 예시 (`q_raw` 수준별, `σ_hit=0.35`):

| `q_raw` | 실패작 | 평작 | 성공작 | 히트작 |
|---|---|---|---|---|
| 0.30 (표준 하단) | ~0.34 | ~0.42 | ~0.21 | ~0.03 |
| 0.55 (우수) | ~0.11 | ~0.36 | ~0.39 | ~0.14 |
| 0.80 (탁월) | ~0.02 | ~0.18 | ~0.42 | ~0.38 |

- 하방 최저(실패작 `q(Q)=0.35`): 게임개발은 `C₀` 없음 → 실패 비용은 개발 기간 급여 매몰. "분산 최대" 정체성 유지하되 완전 손실은 아님 [GD §15-3].
- 꼬리 갱신(라이브운영 B): 출시작당 갱신 횟수 상한 **3회**(영구 수익 차단 [GD §12.3]).

### 5.5 업종 간 서열 (수치 반영 확인)

| 축 | 무역 | 화장품 | 게임개발 |
|---|---|---|---|
| 기대 수익 상한 | 낮음 (`M`×0.9, 시세 ±) | 중간 (자사 라인 고마진) | **최고** (히트작 일시 4.5× + 꼬리 4×) |

## 6. 골드/청산 밸런스

### 6.1 청산 반환 `G_liq`

`G_liq = γ_cash·max(0, 잔액 − 미지급·미납 − C_seed) + γ_up·Σ(C_up 지출 누계)`, 골드 단위 = `÷ ρ_G` [MS §7.4, GD §10.5].

| 기호 | 값 (1차안) | 근거 |
|---|---|---|
| `γ_cash` (잔액 환수율) | **0.50** | 제때 손절이 파산 몰수(0)보다 확실히 낫되, 잔액 절반만 회수 [GD §15-10] |
| `γ_up` (승급비 환수율) | **0.60** | 등급 투자는 잔액보다 약간 후하게(성장 노력 인정), 그래도 <1 |
| `ρ_G` (골드 환산 상수) | **10,000₩/골드** | 청산 산정·설립비 표기 전용. 자금↔골드 직접 교환은 **불가** [GD §5.9] |

- 모든 `γ < 1` + 시드·채무 공제 + 명성·꼬리·직원 투자 미환산 → **왕복 항상 순손실**(가드레일 9).
- 예: 잔액 8,000,000, 채무 0, `C_seed`(무역) 2,000,000, `ΣC_up` 1,200,000 → `G_liq = [0.5·(8M−2M) + 0.6·1.2M]/10,000 = (3,000,000+720,000)/10,000 = 372 골드`. 무역 재설립(`F_found_G=350`) 가능하나, 잔액 8M·명성·직원 전부 소멸 대비 명백한 손실. ✓

### 6.2 업종별 시드·설립비 (가드레일 5: `F_found > C_seed`)

| 업종 | `C_seed` ₩ | `F_found` ₩ | `F_found_G` 골드 | 검증 |
|---|---|---|---|---|
| 무역 | 2,000,000 | 3,500,000 | 350 | `F_found(3.5M) > C_seed(2M)` ✓ |
| 화장품 | 3,500,000 | 5,500,000 | 550 | ✓ |
| 게임개발 | 6,000,000 | 9,000,000 | 900 | ✓ |

- `F_found_G = F_found / ρ_G` (등가 원칙, 1차안). 골드 지불형을 약간 프리미엄으로 둘지는 레버(§9).
- `C_seed`는 창립 편성(계약금 면제) 기준 첫 완료 전 고정 지출을 초과 충당(가드레일 4: §8).

### 6.3 슬롯 해금 페이싱

| 슬롯 | 조건 [GD §10.3] |
|---|---|
| 1 | 게임 시작 |
| n (2..10) | 중기업(3등급)+ 회사가 **n−1곳** (개수 문턱 일반식) |

- 골드 싱크 충분성 [GD §15-11]: 소비처가 설립비뿐이라 후반(슬롯 소진·완주 이후) 골드 적체 가능. MVP 대응 = 청산 골드로 신업종 재도전 순환. **후반 단조로움 점검** — 슬롯 7~10에 등급 문턱 상향(대기업 요구) 옵션을 §9 레버로 유보 [GD §15-12].

| `γ_cash/γ_up` | 크면 성숙 회사 수확 사이클 / 작으면 손절 무의미(좀비 방치) | 0.5/0.6, 왕복 손실 유지하되 파산 몰수 대비 우위 확보 [GD §15-10] |
| `Rep(t)`/`R_up` 비율 | 완주 시간 과단축/과장기화 | 명성 획득량 대비 문턱 스케일 조정, 목표 완주 ~월 75 |
| 계약금 `n_guard` | 낮으면 사이클링 악용 | ≥3개월분 하한 사수 [GD §5.8-8] |

### 9.2 수익화(§monetization) 시간 단축 상품의 밸런스 경계

[README P2] F2P + IAP, **비 페이 투 윈**(결제 = 시간 단축·편의·확장·코스메틱 한정). 본 밸런스가 결제 상품에 그어야 할 경계:

1. **시간 단축은 사이클 진행 가속으로만** — 프로젝트 진척률·`α_auto`·품질·성과 등급 확률·시세 등 **결과 산식에 직접 개입 금지**. 결제는 "같은 결과를 더 빨리"이지 "더 좋은 결과"가 아니다.
2. **자원 6종 직접 판매 금지** — 자금·명성·XP·컨디션·충성도·골드를 상점에서 직접 지급하면 §5.8 가드레일(특히 1·4·9)과 경제 원장 단일 소유가 붕괴. 다이아는 자원이 아닌 실화폐 결제 재화로만([README §2.1]).
3. **골드 판매 주의** — 골드를 IAP로 팔면 설립비 우회가 되어 청산 왕복 손실(가드레일 9)의 억지력이 약화. 판매 시 "설립 편의" 한도로 제한하고 청산 펌프와 무관하게.
4. **완주 페이싱 방어선** — 시간 단축이 완주 목표(~월 75)를 지나치게 압축하면 콘텐츠 소진 리텐션이 무너진다. 가속 상한을 두고 텔레메트리로 완주 분포 모니터([liveops-analytics] 인계).

## 10. 열린 질문

본 문서는 [MS §7]의 함수 형태에 1차안 계수를 채웠다. 아래는 플레이테스트/시뮬레이션으로 확정할 밸런스 수준 질문([GD §15]·[MS §12]와 연동).

1. **`α_auto` 0.72의 명성 파급** — 명성에도 적용되므로 위성 회사 승급 지연이 과도한지. 자금·명성에 서로 다른 `α`를 둘 여지([GD §15-1]).
2. **`Cap_ref(t)` 이원 사용 분리** — 진척 정규화용과 품질/과부하용 커브를 분리할 필요([MS §12-3]).
3. **`σ_hit` × 절단점 결합** — `q_raw`가 `d_c*` 근처일 때 등급 역전 빈도의 허용치([GD §15-3, MS §12-9]).
4. **`γ_cash`/`γ_up` 비중** — 잔액 환수 vs 승급비 환수 상대값, 손절 유인 곡선([GD §15-10]).
5. **`N_found` 차등(3/2)** — 추가 회사 J커브가 충분히 가파른지, 첫 회사와의 차등 폭([GD §15-5]).
6. **컨디션 회복률 차등(90/60)** — 미배치/팀 대기 차등이 "완전 휴식" 결정을 만드는지, 동일화가 나은지([GD §15-6]).
7. **티어 5 × 등급 5 정렬** — 승급 리듬과 티어 상승 리듬이 실플레이 속도에서 1:1로 맞물리는지([GD §15-7]).
8. **자진 강등 악용선** — 부실 진입 충성도 비용 > 유지비 절감이 실제 성립하는지(`pay_loss` 체증 vs `U` 차등)([GD §15-8]).
9. **골드 싱크·후반 슬롯** — 슬롯 소진·완주 후 골드 적체 처리, 슬롯 7~10 등급 문턱 상향 필요성([GD §15-11, §15-12]).
10. **동일 업종 복수 회사** — 전역 시세 `μ` 공유가 무역 병렬 수확이 되는지(`amp` 대역·독립 원장이 충분 억제인지)([GD §15-13]).
11. **`ρ_G`(10,000₩/골드) 표기 상수** — 청산·설립비 환산 전용 상수가 골드 체감 스케일과 맞는지, `F_found_G` 프리미엄 여부.
12. **완주 목표 ~월 75의 활성 시간 환산** — 모바일 방치 가속 하에 25~40시간 타깃이 맞는지, 세션당 사이클 진행량 가정 검증.
