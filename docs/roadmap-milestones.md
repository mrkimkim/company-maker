# MVP 로드맵

MVP 제작에 집중한 로드맵. **마일스톤 → Phase**까지만 여기 두고, **Ticket(SubTask) 상세·진행은 GitHub Issues**가 정본이다(중복 관리 방지). post-MVP(수익화·분석·풀 현지화·알파·베타·런치·운영)는 이연했다(§마지막, `docs/post-mvp/` 참조).

## 상태 범례
`✅` 완료 · `▶` 진행 중 · `☐` 대기 · `👤` 사람/외부 실행 필요

---

## MVP 범위 요약

| # | 마일스톤 | 목표 | 종료 게이트(Exit) | 상태 |
|---|---|---|---|---|
| **M1** | 프리프로덕션·기반 확정 | 착수 블로커 결정·기반 확정 | 결정 로그 + 동결 3종 방향 + 색토큰/데이터 기반 | ▶ 문서·데이터 ✅ / `👤` 대기 |
| **M2** | 프로토타입: 코어 루프 | 무역 1업종으로 코어 루프 재미 검증 | 플레이 가능 + 재미 판정 + 가드레일 실측 | 🔒 스펙 준비됨 |
| **M3** | 버티컬 슬라이스 | 전 시스템 깊이 + 1차 아트/오디오 | 대표 플레이 경험 완성도 | ☐ |
| **M4.1** | 3업종 콘텐츠 | 게임개발·화장품 추가(무역+2) | 3업종 플레이 가능 | ☐ |

> MVP = **플레이·테스트 가능한 빌드**(3업종·코어 루프·전 시스템). 수익화·풀 분석·풀 현지화·런치는 포함하지 않는다.

순서 원칙: **결정 동결(M1) → 결정론 코어(M2) → 시스템 깊이(M3) → 3업종 콘텐츠(M4.1).** 색토큰→대비, 해시/FP/세이브포맷 동결→세이브 구축, 엔진→표현 계층의 선후를 지킨다.

---

## M1 — 프리프로덕션·기반 확정
문서·데이터 SubTask는 완료, `👤`(엔진·스파이크·법무·인력) 실행 대기. 상세 티켓은 GitHub M1 마일스톤.

- **1.1 핵심 설계 결정** — 시간 매핑·`refresh_pool`·게이트 절차·결정 로그 ✅ / 확률 공시 법무 `👤`
- **1.2 기술 기반·엔진 (크리티컬 패스)** — 엔진(C#)·동결 3종(PRNG·FP·세이브포맷)·L1 코어. 계획·권장안 준비(`tech-spikes-and-decisions.md`) `👤`
- **1.3 아트·오디오 스타일** — 색 토큰 v0 ✅ / 스타일·오디오 무드보드·리아 캐스팅 `👤`
- **1.4 데이터·콘텐츠 기반** — 무역 팩·현지화 기반·데이터 스키마 ✅
- **1.5 프로젝트·팀 셋업** — 리포·CI·팀·외주 `👤` (개인정보/약관·브랜드는 post-MVP로 이연)

## M2 — 프로토타입: 코어 루프 검증
착수 준비 완료(무역 팩 로더 TODO 0). 상세는 `m2-prototype-spec.md`(31티켓) = GitHub M2 마일스톤.

- **2.1 결정론 시뮬 코어** — 틱 스케줄러·명령 큐·원장·엔티티·진척·PRNG·고정소수
- **2.2 무역 수직 슬라이스** — 카탈로그 로드·시세·채용/훈련/급여
- **2.3 최소 UI (그레이박스)** — 대시보드·편성·보드·직원 상세·예약 명령
- **2.4 검증·플레이테스트** — 결정론 리플레이·순서 무관성·가드레일 9종·재미 판정·Go/No-Go

## M3 — 버티컬 슬라이스
한 경로에 전 시스템 깊이 + 1차 아트/오디오. 상세는 GitHub M3 마일스톤.

- **3.1 전 시스템 통합** — 자율 주행·멀티 컴퍼니·청산·등급·진행/성장 (크리티컬 패스)
- **3.2 아트·오디오 1차** — UI 키트·아바타·음악/SFX·VFX
- **3.3 온보딩·FTUE** — 튜토리얼리스 온보딩·리아 UX 라이팅·첫 세션
- **3.4 밸런스 1차 튜닝** — 헤드리스 페이싱·최민감 커브 회귀·플레이테스트

## M4.1 — 3업종 콘텐츠
게임개발·화장품 업종 추가(데이터 팩은 이미 준비 — `data/content/{gamedev,cosmetics}.json`). GitHub M4 마일스톤의 M4.1 Epic만 MVP.

- 게임개발(성과 등급·꼬리·흥행 롤) / 화장품(라인 해금·감쇠) 통합·검증
- 업종 확장 계약(`game-design.md §12.8`) 파이프라인 검증

## post-MVP (이연 — MVP 이후)
아래는 MVP 범위 밖. 문서는 `docs/post-mvp/`, GitHub 이슈는 닫힘 처리. 해당 단계 진입 시 승격한다.

- **M4.2 수익화** — 다이아·상점·IAP·구독 (`post-mvp/monetization.md`)
- **M4.3 분석/라이브옵스 계측** — KPI·텔레메트리 (`post-mvp/liveops-analytics.md`)
- **M4.4 풀 접근성·현지화** — 3게이트·ko/en 전량 (`post-mvp/accessibility-localization.md`)
- **M5 알파** — 프리즈·세이브/서버·법무·스토어 (`post-mvp/server-api-and-pipeline.md`, `production-qa-risk.md`)
- **M6 베타·소프트런치** · **M7 글로벌 런치** — 마케팅·UA·런치 (`post-mvp/marketing.md`)
- **M8 라이브 운영·성장** — 콘텐츠/지역 확장 (`post-mvp/liveops-analytics.md`)

> post-MVP의 상세 로드맵·QA·리스크는 `docs/post-mvp/production-qa-risk.md`에 보존.
