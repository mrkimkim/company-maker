# 회사 경영 시뮬레이션 — 사업 마일스톤 마스터 플랜

프로젝트 전체(개발 · 출시 · 배포 · 마케팅)를 **마일스톤 → Phase → SubTask** 3계층으로 정의한 마스터 실행 계획이다. 각 파트 상세는 `docs/`의 해당 문서를 정본으로 참조하며(§는 그 문서의 절), 본 문서는 **순서·의존·게이트·소유**를 통합한다. `production-qa-risk.md §A2`의 Phase 로드맵을 이 3계층 구조로 확장·정합한 것이다.

## 문서의 지위
- 본 문서는 **일정·순서·소유의 정본**이다. 규칙·수치·표현의 정본은 각 파트 문서다.
- 게임 규칙을 바꾸는 결정은 `game-design.md` 개정으로 선행한다(README §2.6).
- 미결 결정·리스크의 집결지는 `production-qa-risk.md §A5·§C9`, 본 문서는 그것을 마일스톤에 배치한다.

## 상태 범례
`☐` 대기 · `▶` 진행 중 · `✅` 완료 · `🔒` 선행 의존 대기 · `👤` 사람/외부 필요(설계·문서로는 준비 가능, 실행은 인력/법무/벤더/계약)
